# Simulations

Small, dependency-free scripts behind figures in the Journal. Each prints the number the article prints.

| Script | What it shows | Article |
|---|---|---|
| `singleton-ticket.mjs` | A random 72-cell ticket carries ≈11.4 singletons and a three-singleton line about one ticket in five — by chance, meaning nothing | [Mohan Srivastava](https://betkyo.com/en/blog/mohan-srivastava-the-statistician-who-read-scratch-tickets-without-scratching-them/) |

More derivations: [odds-derivations](https://github.com/betkyo-open-labs/odds-derivations).
